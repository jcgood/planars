# planars/ package structure

`planars/` is the core library:
- `io.py`: `load_filled_tsv()` — shared TSV loader. `load_filled_sheet(ws, required_criteria)` — same but reads from a gspread Worksheet. Both share `_parse_filled_df` and return `(data_df, keystone_pos, pos_to_name, criterion_cols, keystone_df)`. `keystone_df` carries the keystone rows separately so analyses that need blocking checks against the ROOT (stress, aspiration) can include it without adding the keystone to the position expansion set. Structural validation (`Position_Name` <-> `Position_Number` consistency, exactly one keystone, required-criteria blank check) is enforced via the pandera schemas in `contracts.py`, not inline `if`/`raise` blocks; `_parse_filled_df` catches `pandera.errors.SchemaError` and re-raises `ValueError` so callers see the exception type they always have.
- `contracts.py`: pandera data contracts for two DataFrame boundaries (Phase 6 of the data layer redesign, issue #271). Section 1, `io.py`'s filled-TSV/sheet boundary: `raw_shape_schema(required_criteria)` and `strict_criteria_schema(required_criteria)`. Section 2, `coreference.py`'s pair-row boundary: `coreference_planar_rows_schema()`. See the module docstring for the full rationale, including why section 2 is thinner (most bad values there are deliberately warnings, not failures) and which checks live here vs. inline in each caller.
- `spans.py`: `strict_span`, `loose_span`, `position_sets_from_element_mask`, `fmt_span` — shared span math and formatting helper.
- `ciscategorial.py`, `subspanrepetition.py`, `noninterruption.py`, `stress.py`, `aspiration.py`, `nonpermutability.py`, `coreference.py`, `free_occurrence.py`, `biuniqueness_exponence.py`, `repair.py`, `segmental.py`, `metrical.py`, `tonal.py`, `tonosegmental.py`, `intonational.py`, `pausing.py`, `proform.py`, `play_language.py`, `idiom.py`: each exposes `derive_*()` (takes an optional `Path` or `_data` kwarg, returns a result dict) and `format_result()` (takes a result dict, returns a formatted string). `coreference.py` differs from the standard pattern: takes pair-row TSVs (one per construction: `reflexivization`, `pronominalization`, `np_reference`); derives binder/bindee domains rather than complete/partial position sets; prescreening construction (`prescreening`, criterion `referential`) feeds element sets to the three pair constructions. Column presence for both the planar and pair TSVs, and the planar TSV's `Position`-castable-to-`int`/keystone-exists checks, are enforced explicitly (Phase 6, issue #271 — see `contracts.py` section 2); per-row value leniency (an unrecognized element, an unparseable `Position_B`) stays exactly as it was, collected into `missing_data` rather than failed outright. `proform.py` differs from the standard complete/partial pattern: criterion `shareable_proform_replace` (`y`=strict, `both`=loose, `n`) feeds two separate element masks to `position_sets_from_element_mask` independently.
- `reports.py`: data layer for all downstream analysis. Owns `_CLASS_HANDLERS` (analysis registry), `project_spans`/`language_spans` (span collection), `language_report_data` (full bundle for rendering), and span label constants. Also owns `_REPORTABLE_CONSTRUCTIONS` — a per-class filter that blocks non-span-producing constructions (e.g. `element_prescreening`) from being passed to derive functions; any code iterating constructions for display or analysis should apply this filter.
- `html_report.py`: `render_language_report(data)` → self-contained HTML string (Plotly chart). `render_language_report_pdf(data)` → PDF bytes (requires `weasyprint` + `kaleido`).
- `charts.py`: visualization only. Imports `_CLASS_HANDLERS` and span collection from `reports.py`. `domain_chart(df, keystone_pos, pos_to_name)` — single-language chart (caller filters df by language first). `charts_by_language(df, lang_meta)` — produces one chart per language, returns `dict[lang_id, Figure]`. Span label constants re-exported for backward compat.
- `cli.py` + `__main__.py`: CLI entry point (`python -m planars <analysis> <tsv>`).
