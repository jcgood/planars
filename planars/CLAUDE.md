# planars/ package structure

`planars/` is the core library:
- `io.py`: `load_filled_tsv()` — shared TSV loader. `load_filled_sheet(ws, required_criteria)` — same but reads from a gspread Worksheet. Both share `_parse_filled_df` and return `(data_df, keystone_pos, pos_to_name, criterion_cols, keystone_df)`. `keystone_df` carries the keystone rows separately so analyses that need blocking checks against the ROOT (stress, aspiration) can include it without adding the keystone to the position expansion set.
- `spans.py`: `strict_span`, `loose_span`, `position_sets_from_element_mask`, `fmt_span` — shared span math and formatting helper.
- `ciscategorial.py`, `subspanrepetition.py`, `noninterruption.py`, `stress.py`, `aspiration.py`, `nonpermutability.py`, `coreference.py`, `free_occurrence.py`, `biuniqueness_exponence.py`, `repair.py`, `segmental.py`, `metrical.py`, `tonal.py`, `tonosegmental.py`, `intonational.py`, `pausing.py`, `proform.py`, `play_language.py`, `idiom.py`: each exposes `derive_*()` (takes an optional `Path` or `_data` kwarg, returns a result dict) and `format_result()` (takes a result dict, returns a formatted string). `coreference.py` differs from the standard pattern: takes pair-row TSVs (one per construction: `reflexivization`, `pronominalization`, `np_reference`); derives binder/bindee domains rather than complete/partial position sets; prescreening construction (`prescreening`, criterion `referential`) feeds element sets to the three pair constructions. `proform.py` differs from the standard complete/partial pattern: criterion `shareable_proform_replace` (`y`=strict, `both`=loose, `n`) feeds two separate element masks to `position_sets_from_element_mask` independently.
- `reports.py`: data layer for all downstream analysis. Owns `_CLASS_HANDLERS` (analysis registry), `project_spans`/`language_spans` (span collection), `language_report_data` (full bundle for rendering), and span label constants. Also owns `_REPORTABLE_CONSTRUCTIONS` — a per-class filter that blocks non-span-producing constructions (e.g. `element_prescreening`) from being passed to derive functions; any code iterating constructions for display or analysis should apply this filter.
- `html_report.py`: `render_language_report(data)` → self-contained HTML string (Plotly chart). `render_language_report_pdf(data)` → PDF bytes (requires `weasyprint` + `kaleido`).
- `charts.py`: visualization only. Imports `_CLASS_HANDLERS` and span collection from `reports.py`. `domain_chart(df, keystone_pos, pos_to_name)` — single-language chart (caller filters df by language first). `charts_by_language(df, lang_meta)` — produces one chart per language, returns `dict[lang_id, Figure]`. Span label constants re-exported for backward compat.
- `cli.py` + `__main__.py`: CLI entry point (`python -m planars <analysis> <tsv>`).
